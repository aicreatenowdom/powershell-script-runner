## Help us reproduce the problem

Include the Script Runner version, Windows version, steps to reproduce and the exact error text. Say whether the same script runs directly in PowerShell. Share only a small, reviewed example when it is necessary to explain a launcher issue.

Keep passwords, access tokens, license keys and private customer information out of public issues and screenshots. Send purchase or delivery questions directly by email.

## Before contacting support

- Distinguish an application launch failure from an error printed by the selected script.
- Include the exact console error and confirm that the selected file still exists at its saved path.
